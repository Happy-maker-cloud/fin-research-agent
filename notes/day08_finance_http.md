# 金融知识

## 1.股票	
股票代表公司部分所有权
根据持股数进行分红
市值:股价*总股数
PE：市值/年度归母净利润  相当于投资多少倍的本金能够得到一倍的利润
PB：市值/归属于普通股股东的净资产  投资多少倍的钱能相当于一倍的家底
ROE：年度归母净利润/平均归母净资产  每份资产能带来多少收益

## 2.基金
集合投资者的资金，按约定规则投资
净值＝基金净资产 ÷ 总份额，表示每份基金背后的资产价值。
ETF市场价格＝交易所实际买卖价格；高于净值叫溢价，低于净值叫折价。

## 3.资产负债表
记录公司在某个时点“有什么、欠多少、剩下多少属于股东”的报表

## 4.利润表
记录公司在一段时间内“做了多少生意、花了多少钱、最后赚了多少”的报表

## 5.现金流量表
记录公司在一段时间内“现金从哪里来、花到哪里去”的报表

## 6.投资组合
把资金分配到多个投资品种中
组合收益看权重与各项收益率；组合风险还要看各项资产的波动和相互之间的相关性。 相关性也会变化，分散投资不能保证不亏损。

## 7.风险
| 风险指标或类型 | 主要看什么 |
| **波动率** | 收益率上下变化有多剧烈 |
| **最大回撤** | 历史上从高点到后续低点，最多跌了多少 |
| **流动性风险** | 能否及时以合理价格成交 |
| **数据风险** | 用来分析的数据是否正确、完整、及时 |
| **模型风险** | 分析方法是否存在错误或失效 |
波动率看涨跌幅度，最大回撤看从高点跌了多深，流动性看能否成交，数据和模型风险看分析结论是否可靠。

## 8.风控与合规意识
让金融分析有依据、能追溯，同时避免误导用户或泄露敏感信息
| 要点 | 具体做法 | 示例 |
| **来源** | 标明数据来自哪里，优先使用可核验的原始来源 | “来源：公司2025年年度报告” |
| **日期** | 区分数据所属日期、发布日期和获取时间 | 2025年利润，在2026年公布；不能当成2026年利润 |
| **证据** | 结论对应具体数据、原文或计算过程 | “净利润增长20%”，应给出两年的利润与计算方式 |
| **不确定性** | 区分事实、推测和预测，说明缺失信息 | “利润增长已确认，但能否持续仍取决于后续订单” |
| **敏感数据保护** | 只收集必要信息，限制访问，避免出现在日志或公开输出中 | API密钥、账户信息、身份证号不应直接打印 |

## 金融Agent回答规则

1. 行情回答注明实际数据日期、数据来源。
2. 财报回答区分报告期和发布日期。
3. 数据缺失时说明缺失，不编造数值。
4. 区分已知事实、推算结果和模型判断。
5. 不承诺收益，不把历史回测当成未来保证。
